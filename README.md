> **Faculty:** Science by Dheeraj Sir  
> **Target Exams:** Railway (NTPC, ALP, Group D, Technician), Bihar (SI, Police Constable), SSC (CGL, CHSL, GD), and State Competitive Exams.

---

## 🚀 Overview
**TIME PLUS** is a next-generation, high-performance coaching and educational platform built to provide students with an interactive classroom experience on mobile and web devices.

### 🌟 Core Modules:
1. 🔴 **Live Classes & Real-Time Chat**: Attend live sessions with faculty, ask questions, and interact with peers.
2. 🎬 **VOD (Video on Demand)**: Recorded video lectures with playback speed controls (0.75x to 2x), quality switcher (360p to 1080p), and dynamic floating watermarks for anti-piracy protection.
3. 📝 **Online CBT Test Section**: Full Computer-Based Test engine with live countdown timer, question palette, negative marking, and instant detailed solutions & analytics.
4. 📑 **PDF Holder & Lecture Notes**: Integrated digital board class notes reader with watermark protection and zoom controls.
5. 📥 **Offline Download Mode**: Save lectures and notes to watch and study anywhere without an internet connection.
6. 🛠️ **Teacher Admin Dashboard**: Manage courses, live classes, videos, notes, and tests without writing a single line of code.

## 🛠️ Tech Stack
- **Frontend Framework:** React 19 + Vite
- **Styling & UI:** Tailwind CSS + Lucide Icons
- **Celebration Effects:** Canvas Confetti
- **Deployment:** Progressive Web App (PWA) & Mobile Web

## 💻 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
